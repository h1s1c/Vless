# VLESS Config Converter

وب‌اپ ساده و استاتیک برای تبدیل یک URL از نوع VLESS به قالب ثابت تعریف‌شده در `script.js`.

## اجرا در کامپیوتر
فایل `index.html` را در مرورگر باز کنید. برای Clipboard API بهتر است از HTTPS یا localhost استفاده کنید.

## انتشار با GitHub Pages
1. یک Repository جدید در GitHub بسازید.
2. فایل‌های `index.html`، `style.css` و `script.js` را در ریشه Repository آپلود کنید.
3. به **Settings → Pages** بروید.
4. در **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
5. Branch را روی `main` و پوشه را روی `/(root)` بگذارید و Save کنید.
6. پس از انتشار، لینک نمایش‌داده‌شده در بخش Pages را باز کنید.

## رفتار
- مقصد خروجی ثابت: `mtn.vip2vip.info:443`
- UUID و نام از ورودی حفظ می‌شوند.
- پارامترهای خروجی و Fragment طبق قالب ثابت در کد ساخته می‌شوند.
- اعتبارسنجی فقط ساختار و پارامترها را بررسی می‌کند؛ دسترسی‌پذیری سرور را آزمایش نمی‌کند.
- پردازش در مرورگر انجام می‌شود و کانفیگ به سرور این برنامه ارسال نمی‌شود.

## نکته امنیتی
کانفیگ‌ها ممکن است حاوی شناسه یا اطلاعات اتصال باشند. از واردکردن کانفیگ‌های حساس در دستگاه‌های عمومی خودداری کنید.
